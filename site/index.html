About this atlas

The study profiles single-cell chromatin accessibility across nine mouse tissues, identifying tissue-specific regulatory programs in 28 major cell types. The atlas provides an interactive view of the study's processed accessibility data, precomputed cell identities, and selected gene-activity scores.

Paper: Chromatin accessibility landscapes define stromal cell identities across tissues · Communications Biology (2026).

Genome assembly: mm10. Gene activity is an ATAC-derived measure, not RNA expression. This study contains nine mouse-tissue single-cell ATAC-seq datasets; cross-sample feature integration requires common genomic intervals, not concatenation of tissue-specific peak matrices.
